# 문자열 덧셈 계산기

---

## 1. 미션 개요
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.


## 2. 구현 기능 목록
- [ ] 사용자로부터 문자열을 입력받는 기능
  - [ ] [예외 상황] 구분자만 입력된 경우
  - [ ] [예외 상황] 숫자만 입력된 경우
  - [ ] [예외 상황] 기본 구분자가 쉼표(,) 또는 콜론(:) 이 아닌 경우
  - [ ] [예외 상황] 숫자가 0 또는 음수인 경우
  - [ ] [예외 상황] 잘못된 형식인 경우 (ex - 1,2:)
  - [ ] [예외 상황] 입력된 값이 없는 경우
- [x] 구분자를 기준으로 분리한 각 숫자의 합을 계산하는 기능
  - [x] 기본 구분자로 숫자를 분리할 수 있다.
  - [x] 커스텀 구분자로 숫자를 분리할 수 있다.
    - [x] 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- [ ] 계산 결과를 출력하는 기능
